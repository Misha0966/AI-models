**Введение**

Данный проект представляет собой исследование и разработку простой модели нейросети в контексте обработки 3D-данных с использованием линейной алгебры. Модель ориентирована на обучение с использованием случайных данных, где основное внимание уделяется преобразованиям данных в 3D-пространстве. Проект включает в себя создание и обучение нейросетевой модели, способной обрабатывать и предсказывать преобразованные 3D-координаты, применяя различные математические методы.

**Цели и задачи:**

Цель проекта — создание и тренировка нейросети для обработки данных в 3D-пространстве с применением вращения данных на определённый угол вокруг оси Z. Задачи включают:

# 1. Генерация случайных 3D-данных и их преобразование с использованием матрицы вращения.
    
# 2. Построение модели нейросети для предсказания преобразованных данных.
    
# 3. Обновление параметров модели (весов и смещений) с использованием ошибки между предсказаниями и реальными данными.
    
# 4. Оценка качества модели на основе ошибки предсказания (MSE).

**Структура проекта:**

## 1. Модели данных:

SimpleModel: Модель нейросети, которая включает матрицу весов и вектор смещений. Основная задача — умножение входных данных на веса и добавление смещений для получения предсказаний.

## 2. Процесс обучения:

Используется метод, схожий с градиентным спуском, для обновления весов и смещений на основе ошибки между предсказаниями модели и реальными данными.

Для эффективного обучения реализована обработка данных с использованием батчей.

## 3. Генерация данных:

Сначала генерируются случайные 3D-данные, после чего они подвергаются вращению с заданным углом.

Модель обучается на этих данных, а затем тестируется на новых примерах.

## 4. Функции для преобразования данных:

rotor_transform_3d: Функция для выполнения вращения 3D-данных с использованием матрицы вращения.

generate_data_3d: Функция для генерации случайных 3D-точек и их преобразования.

train_rotor_model: Основная функция для тренировки модели, которая генерирует данные, обучает модель и выводит результаты.

## 5. Описание процесса обучения:

**Процесс обучения модели включает несколько этапов:**

### 1. Генерация данных: случайные 3D-координаты генерируются и затем подвергаются вращению на заданный угол.

### 2. Инициализация модели: модель создаётся с случайными весами и смещениями.
    
### 3. Обучение модели: модель обновляет веса и смещения на основе ошибки между предсказаниями и реальными значениями, что позволяет минимизировать ошибку.
### 4. Оценка модели: каждая эпоха обучения выводит информацию о текущей ошибке (среднеквадратичной ошибке), чтобы отслеживать процесс обучения.
### 5. Тестирование модели: после завершения обучения модель проверяется на новых данных для проверки качества предсказаний.

## 6. Пример использования:

Для обучения модели задаются следующие параметры:

samples: количество примеров для обучения.

angle: угол вращения данных (в радианах).

epochs: количество эпох для обучения.

learning_rate: скорость обучения.

batch_size: размер батча.

## 7. Пример запуска модели:

samples = 10000  # Количество примеров для обучения

angle = π / 4    # Угол вращения (45 градусов)

epochs = 50      # Количество эпох обучения

learning_rate = 0.0001  # Скорость обучения

batch_size = 32  # Размер батча

model = train_rotor_model(samples, angle, epochs, learning_rate, batch_size)

После обучения модель можно протестировать на новых данных:

x_test, y_test = generate_data_3d(10, angle)

predictions = model(x_test)

println("Оригинальные данные:\n$y_test")

println("Предсказания модели:\n$predictions")

## 8. Заключение:

Этот проект представляет собой создание и обучение нейросети для обработки 3D-данных с использованием матричных преобразований. Он иллюстрирует базовые принципы работы с нейросетями, обновлением параметров модели и обработки данных в 3D-пространстве.
