Микробный интеллект.

О проекте:

Этот проект представляет собой симуляцию жизни микробных существ в искусственной среде. Я создаю виртуальных организмов (микробов), которые взаимодействуют с окружающей средой, могут размножаться, собирать пищу и адаптироваться к условиям. 

Главная цель — показать, как организмы могут развиваться в ответ на изменения в среде, такие как наличие пищи, токсичных зон и другие экологические факторы.

Проект использует модель, где:

Микробные клетки имеют свою энергию, скорость и память.

Организмы могут размножаться, если они накапливают достаточно энергии.

В среде есть токсичные зоны, которые вредят организмам.

Этот проект предназначен для тех, кто интересуется моделями биологических систем и исследованиями в области искусственного интеллекта, обучения и адаптации.

Как это работает?

Организмы: Каждый организм состоит из нескольких микробных клеток. Каждая клетка имеет свою энергию, скорость и стратегию поведения. Организм может собирать пищу, избегать токсичных зон, размножаться и мутировать.

Среда: Среда — это поле с размерами 100x100, в котором расположены организмы. В некоторых клетках есть пища, а в других — токсичные зоны, которые вредят организмам.

Поведение: Организмы могут искать пищу, избегать токсичных зон, размножаться и мутировать. Они адаптируются к среде и становятся более «умными» с каждым шагом.

Результаты: В ходе симуляции можно наблюдать за поведением организмов, их передвижением по сетке, собранной пище и выживанием. Результаты сохраняются в виде анимации и таблицы.

Основные функции:

Поиск пищи: Организмы ищут пищу в клетках с положительными значениями. Когда они находят пищу, их энергия увеличивается.

Токсичные зоны: В некоторых клетках есть токсичные зоны, которые уменьшают энергию организма.

Размножение: Когда организм набирает достаточно энергии, он может размножиться, создав потомков.

Мутации: Геном каждого организма может мутировать с каждым шагом, что может повлиять на его поведение.

Процесс симуляции — это серия шагов, в ходе которых мы наблюдаем, как организмы взаимодействуют с окружающей средой, изменяются и адаптируются.

Установка и использование

Требования:

Для работы с этим проектом нужно установить несколько библиотек в языке программирования Julia:

Random — для генерации случайных чисел.

Plots — для создания графиков и визуализаций.

CSV — для записи данных в CSV файл.

DataFrames — для работы с таблицами данных.

Как запустить:

Убедитесь, что у вас установлен язык программирования Julia. Если нет, его можно скачать на оффициальым сайте: 

https://julialang.org

Установите необходимые библиотеки, выполнив в Julia следующие команды:

using Pkg

Pkg.add("Random")

Pkg.add("Plots")

Pkg.add("CSV")

Pkg.add("DataFrames")

Скопируйте код из этого репозитория. Затем вставьте его в свой файл в VS Сode, с раширением .jl. После чего выполните его. 

Если не установлен VS Code, то нужно его скачать с оффициального сайта: https://code.visualstudio.com

Что произойдет:

Будет создана среда с клетками, содержащими пищу и токсичные зоны.

Будет инициализирована популяция организмов.

Организмы начнут выполнять действия (поиск пищи, избегание токсичных зон, размножение, мутации).

Результаты симуляции будут сохранены в два файла:

microbial_simulation.gif — анимация с движением организмов по клеткам.
microbial_results.csv — таблица с данными о шагах, координатах организмов, их энергии и других параметрах.

Пример данных в таблице:

step — номер шага симуляции.

x, y — координаты организма на поле.

energy — текущая энергия организма.

food_collected — сколько пищи собрал организм.

steps_survived — сколько шагов организм выжил.

Применение

Этот проект может быть использован для:

Изучения принципов эволюции и адаптации в искусственных системах.

Разработки алгоритмов для искусственного интеллекта, которые могут «обучаться» и «адаптироваться» к изменениям в их окружении.

Исследования поведения организмов в изменяющихся условиях, что может быть полезно в биологических и экологических исследованиях.

Заключение:

Проект — это простая, но мощная симуляция, которая может быть полезной для понимания принципов работы адаптивных систем, эволюции и самообучения. 

Мы можем наблюдать, как даже простые организмы могут эволюционировать и взаимодействовать с окружением, что позволяет глубже понять основные принципы биологических и интеллектуальных систем.
